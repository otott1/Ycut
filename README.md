# قص يوتيوب (YoutubeCut)

تطبيق أندرويد بنفس فكرة سكربت `YoutubeCut.py`:

1. يطلب مفتاح Gemini مرة واحدة فقط ويحفظه على الجهاز.
2. تلصق رابط فيديو يوتيوب طويل.
3. يقترح Gemini المقاطع (عنوان + وقت البداية والنهاية + المدة).
4. تختار ما تريد، فيُحمَّل **المقاطع المختارة فقط** (لا يُحمَّل الفيديو كاملاً).

المقاطع تُحفظ في `Movies/YoutubeCut/<عنوان الفيديو>` (أو `Music/` عند اختيار «صوت فقط»).

## بناء ملف APK

### الطريقة الأسهل: GitHub Actions (لا تحتاج حاسوباً)

من Termux:

```bash
pkg install -y git
cd YoutubeCut
git init -b main
git add .
git commit -m "init"
# أنشئ مستودعاً فارغاً على github.com ثم:
git remote add origin https://github.com/USERNAME/YoutubeCut.git
git push -u origin main      # كلمة المرور = Personal Access Token
```

ثم في صفحة المستودع: **Actions ← Build APK ← انتظر ~10 دقائق ← Artifacts ← YoutubeCut-apk**.
نزّل الملف، فكّ الضغط، وثبّت `app-debug.apk` (اسمح بالتثبيت من مصدر غير معروف).

إن فشل البناء: افتح الـ run الفاشل وانسخ سطور الخطأ (تبدأ بـ `e:` أو `error:`).

### Android Studio

افتح المجلد، انتظر مزامنة Gradle، ثم Build ← Build APK.

## ملاحظات

- **تحديث yt-dlp**: يوتيوب يغيّر آلياته كثيراً. التطبيق يحدّث yt-dlp تلقائياً (قناة nightly) كل 24 ساعة،
  وفي الإعدادات زر «تحديث المحرك الآن».
- **نموذج Gemini**: يختار التطبيق أحدث نموذج Flash متاح لمفتاحك من قائمة Google الفعلية،
  ويمكنك تثبيت نموذج بعينه من الإعدادات.
- **المفتاح** يُحفظ في تخزين التطبيق الخاص ولا يدخل النسخ الاحتياطي السحابي.
- إن ظهرت رسالة «يطلب يوتيوب التحقق من أنك لست روبوتاً»: جرّب شبكة أخرى أو أعد المحاولة لاحقاً.
- بدون ترجمة للفيديو، يحلّل Gemini الفيديو مباشرة من الرابط (أبطأ ويستهلك حصة أكبر).
- المشاركة: من تطبيق يوتيوب اضغط «مشاركة ← قص يوتيوب» ويبدأ التحليل مباشرة.
- القص بنسخ الصوت والصورة دون إعادة ترميز (سريع)، لذا قد يبدأ المقطع بأقرب إطار مفتاحي قبل النقطة المطلوبة.
- الترخيص: مكتبة youtubedl-android بترخيص GPL-3.0، وهذا يناسب الاستخدام الشخصي.
